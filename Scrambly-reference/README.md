# Scrambly — assessment reference

Scrambly is a rewards platform for discovering mobile games and apps,
completing eligible activities and redeeming rewards.

Official product reference: https://scrambly.io/
Reviewed: September 15, 2026.

For this exercise, create a short playable ad that connects an enjoyable
experience with a reason to explore Scrambly. Choose your concept,
mechanics, visual approach and 2D/3D format.

The fox artwork comes from Simula's existing advertiser materials. The
working palette is suggested by that reference, not an official brand
standard. You may use the reference or develop another coherent treatment.
This kit contains a raster reference; it does not include a rigged 3D model.

Reward balances inside your playable are simulated. Keep product claims
accurate; guaranteed income and real payouts are not part of this demo.

Files:
- scrambly-fox-reference.webp — supplied mascot artwork, 294 × 320 pixels.
- working-palette.json — suggested colors.

Keep credits for additional material you source. The full assessment HTML
contains the delivery requirements, timing, submissions and evaluation.
